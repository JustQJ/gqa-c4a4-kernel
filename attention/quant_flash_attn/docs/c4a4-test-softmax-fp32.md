# C4A4 FP32 Softmax 测试范围与参数设置

更新日期：2026-11-11。

本文分为精度测试范围和性能测试范围，各自包含全量测试与小量测试。小量测试统一限定为 **Qwen3.6 配置、TP=2**；小量精度的 MTP 进一步限定 Q 长度和 batch，小量性能的 Decode/MTP 进一步限定 batch，其余输入保持对应全量范围。下述数量表示测试范围，不表示已通过数量。

长度单位为 token，1k=1024；8k、32k、64k、128k、256k 分别为 8192、32768、65536、131072、262144。Q/KV 长度列表按序列逐项配对，列表长度就是 batch。除明确给出不等长列表的场景外，同一个 batch 内各序列等长；表中列出的 batch、Q、KV 选项按全部组合展开。

## 1. 精度测试范围

量化参数 `quant_mode=5`。P量化选择 `quant_schema=0/1/2` 分别对应普通MXFP4/OCP、CX（不乘1.5）和CX Delta；默认2。全量和小量输入范围均可按三种方案分别展开，以下数量均为**单个方案**的数量。小量含主矩阵204项和基础检查24项，每种228项，三种共684项；每种方案都覆盖相同的无mask/causal、DN/ND和page范围。

### 1.1 全量测试

**模型与 TP 设置**

三个模型参数组均覆盖 TP=1、2、4。N1 为当前 TP 下的 Q 头数，N2 为 KV 头数，G 为每个 KV 头对应的 Q 头数。TP 表示测试采用的单卡头数配置。

| 模型参数组 | D=Dv | TP=1：N1/N2/G | TP=2：N1/N2/G | TP=4：N1/N2/G |
| --- | --- | --- | --- | --- |
| Qwen3.6（35B 配置） | 256 | 16/2/8 | 8/1/8 | 4/1/4 |
| Qwen3.8（27B 配置） | 256 | 24/4/6 | 12/2/6 | 6/1/6 |
| Qwen3（30B 配置） | 128 | 32/4/8 | 16/2/8 | 8/1/8 |

**主矩阵输入范围**

每一种输入均覆盖 **无 mask、causal × DN、ND × 三个模型 × TP=1/2/4**，每种输入展开为 36 项。

| 场景 | 每条 Q 长度 | 每条 KV 长度 | batch | page | 输入组合数 | 全量检查数 |
| --- | --- | --- | --- | --- | --- | --- |
| 短输入 | 1、3、4、5、11、22 | 与 Q 相同 | 1 | 与 Q 依次对应 128、128、256、512、512、128 | 6 | 216 |
| 不等长混合输入 | [1,3,22,129] | [11,32771,65,259] | 4 | 128 | 1 | 36 |
| 大 batch 不等长输入 | 下述 Q 基础列表重复 3 次 | 下述 KV 基础列表重复 3 次 | 36 | 128 | 1 | 36 |
| 原长 KV prefill | 129 | 32771 | 1 | 512 | 1 | 36 |
| 长 Q prefill | 8192 | 8192、32768、65536 | 1、2 | 512 | 6 | 216 |
| MTP | 1、2、3、4、5、6、7、8 | 32768、65536、131072 | 1、2、4、8、16 | 256 | 120 | 4320 |
| **合计** | | | | | **135** | **4860** |

batch=36 的基础长度列表为：

- Q：[1,3,4,5,11,22,102,300,512,1024,3000,4096]。
- KV：[1,17,65,127,33,65,202,330,891,1999,3100,5196]。

两个列表分别按原顺序重复三遍，形成 36 对序列长度。长 Q prefill 的三种 KV 长度分别成例，例如 batch=2、KV=65536 表示两条序列的 KV 长度均为 65536。

主矩阵数量为 **135 种输入 × 2 mask × 2 方向 × 3 模型 × 3 TP = 4860 项**。每个模型 1620 项，DN/ND 各 2430 项，无 mask/causal 各 2430 项。

**补充输入范围（不计入 4860 项）**

| 场景 | Q / KV / batch / page | 模型和 TP | mask 与方向 | 检查数 |
| --- | --- | --- | --- | --- |
| 冒烟 | Q=17，KV=257，batch=1，page=256 | 三个模型，TP=1/2/4 | 两种 mask × DN/ND | 36 |
| 不等长混合输入重复 | Q=[1,3,22,129]，KV=[11,32771,65,259]，batch=4，page=128；重复 5 轮 | Qwen3（30B 配置），TP=1/2/4 | 两种 mask × DN/ND | 60 |
| 跨 Q 压力 | Q=641 或 32769，KV=65，batch=1，page=128 | 三个模型，TP=1/2/4 | 两种 mask × DN/ND | 72 |

**数据与参数设置**

| 参数 | 设置 |
| --- | --- |
| Q/K/V 数据类型 | MXFP4 E2M1；随机覆盖全部 16 个编码，包含正负数和零 |
| 随机种子 | 421；混合输入重复测试使用相同输入 |
| Q/K descale | E8M0 编码随机取 122～125；沿 QK 归约维度每 32 个元素共享 scale |
| V descale | E8M0 编码随机取 124～127；沿 KV token 维度每 32 个元素共享 scale |
| Q / 输出布局 | TND / TND |
| KV 布局 | PA_BBND；各序列使用独立物理页，页号随机打乱，额外保留 3 个未使用页 |
| page size 范围 | 仅 128、256、512；各用例取值按输入范围表固定 |
| DN 的 Q descale 布局 | TND |
| ND 的 Q descale 布局 | N2TGD |
| Q 长度设置 | DN 显式提供每条序列有效 Q 长度；ND 由累计 Q 长度确定 |
| 长度与页表类型 | int32 |
| mask | 无 mask：mask_mode=0；右下对齐 causal：mask_mode=3 |
| causal 模板 | int8，2048×2048；模板尺寸不限制序列长度 |
| 量化模式 | C4A4 mode5，CX Delta P 量化，x=7.25、delta=1.5 |
| Softmax 缩放 | 显式设置为 1/√D |
| Attention 输出 | BF16 |
| LSE 输出 | 开启，FP32 |
| FD 分片数 | 自动决定，不固定指定 |
| 精度参考 | PyTorch 与 Triton 双参考 |
| 精度阈值 | Attention 输出对同舍入 BF16 参考及 FP32 LSE 的最大绝对误差均小于 1e-5；非有限值须匹配，不允许 NaN |

causal 为右下对齐：序列内 Q 位置 i 可见的 KV 位置 j 满足 j≤i+KV长度−Q长度。跨 Q 压力用例中 Q 长于 KV，部分 Q 行没有可见 KV，此时预期 Attention 输出为零、LSE 为正无穷。page 取值按主矩阵表固定，不对每个输入额外展开全部 page size。

### 1.2 小量测试

**仅保留 Qwen3.6（35B 配置）、TP=2**；MTP 的每条 Q 长度限定为 **1、2、3、4**，batch 限定为 **1、2、16**，KV 长度仍为 32768、65536、131072。非 MTP 输入与 1.1 一致，全部输入继续覆盖无 mask、causal 和 DN、ND。

| --- | --- |
| 模型 | Qwen3.6（35B 配置） |
| TP | 2 |
| D / Dv | 256 / 256 |
| Q 头数 N1 | 8 |
| KV 头数 N2 | 1 |
| G | 8 |
| Q / KV 长度、batch | 按下表设置 |
| page size 范围 | 仅 128、256、512；各用例取值按下表固定 |
| mask | 无 mask、右下对齐 causal |
| 方向 | DN、ND |
| 数据、缩放、输出及精度参数 | 与 1.1 一致 |

| 主矩阵场景 | 每条 Q 长度 | 每条 KV 长度 | batch | page | 输入组合数 | 小量检查数 |
| --- | --- | --- | --- | --- | --- | --- |
| 短输入 | 1、3、4、5、11、22 | 与 Q 相同 | 1 | 与 Q 依次对应 128、128、256、512、512、128 | 6 | 24 |
| 不等长混合输入 | [1,3,22,129] | [11,32771,65,259] | 4 | 128 | 1 | 4 |
| 大 batch 不等长输入 | 1.1 的 Q 基础列表重复 3 次 | 1.1 的 KV 基础列表重复 3 次 | 36 | 128 | 1 | 4 |
| 原长 KV prefill | 129 | 32771 | 1 | 512 | 1 | 4 |

小量 MTP 为 **4 种 Q 长度 × 3 种 KV 长度 × 3 种 batch = 36 种输入**，展开两种 mask 和 DN/ND 后为 144 项。其余 15 种输入展开后为 60 项。

小量主矩阵为 **51 种输入 × 2 mask × 2 方向 = 204 项**，DN/ND 各 102 项，无 mask/causal 各 102 项。

补充测试沿用 1.1 的长度、batch、page 和重复轮数，模型统一改为 Qwen3.6、TP 固定为 2：冒烟 4 项、不等长混合输入五轮重复 20 项、跨 Q 压力 8 项，均覆盖两种 mask 和 DN/ND，不计入 204 项主矩阵。

## 2. 性能测试范围

C4的P量化参数默认 `quant_schema=2`；与C8对比时，C8保持其原量化模式。本文列出输入范围，不代表本轮执行性能测试。

### 2.1 全量测试

**模型与 TP 设置**

使用与 1.1 相同的三个模型参数组及其头数：Qwen3.6（35B 配置）、Qwen3.8（27B 配置）、Qwen3（30B 配置），每组覆盖 TP=1、2、4，共 9 组模型/TP 配置。

**输入范围**

| 场景 | 每条 Q 长度 | 每条 KV 长度 | batch | page | 方向 | 每组模型/TP 的场景数 | 全量场景数 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Prefill | 8192 | 8192、32768、65536、131072、262144 | 1、2、4 | 256 | DN | 15 | 135 |
| Decode/MTP | 1、2、4、6、8 | 32768、65536、131072、262144 | 1、2、4、8、16、32、64 | 256 | ND | 140 | 1260 |
| **合计** | | | | | | **155** | **1395** |

每个 batch 内序列等长。每种场景分别测试 C4A4 与 C8A8，使用数值等价的 Q/K/V 输入进行配对比较。全量为 **155 种输入 × 3 模型 × 3 TP = 1395 项配对性能场景**，每项同时包含 C4A4 和 C8A8 的测量。

性能范围固定为 **仅 causal、Prefill 使用 DN、Decode/MTP 使用 ND**；不额外展开无 mask 或另一方向，不包含 batch=36 不等长输入，MTP Q 长度取 1、2、4、6、8。

**数据与参数设置**

| 参数 | 设置 |
| --- | --- |
| C4A4 输入 | MXFP4 E2M1，随机 FP4 编码 |
| C8A8 输入 | MXFP8 E4M3，与 C4A4 输入数值等价 |
| 随机种子 | 20261111 |
| Q/K descale | E8M0 编码固定为 123 |
| V descale | E8M0 编码固定为 125 |
| Q / 输出布局 | TND / TND |
| KV 布局 | PA_BBND；各序列独占物理页，页号随机打乱 |
| page size | 256 |
| DN / ND 的 Q descale 布局 | DN 为 TND；ND 为 N2TGD |
| mask | 右下对齐 causal，mask_mode=3 |
| causal 模板 | int8，2048×2048 |
| 量化模式 | C4A4 mode5、CX Delta P 量化，x=7.25、delta=1.5；C8A8 mode1 |
| C8A8 的 P scale | 448 |
| Softmax 缩放 | 显式设置为 1/√D |
| Attention 输出 | BF16 |
| LSE 输出 | 关闭 |
| FD 分片数 | 自动决定，不固定指定 |
| 预热与采样 | 预热 3 次；5 轮采样，每轮每种实现重复 20 次 |
| 汇总参数 | 每轮按单次平均耗时计，最终取 5 轮中位数 |
